# 🚀 API - Backend - Programação IV

Este é o projeto contínuo desenvolvido para a disciplina de Programação IV, evoluindo a cada aula (Aula 07 até Aula 12). Aqui encontram-se as rotas, regras de negócio e a ligação à base de dados.

## 📋 Progresso das Atividades

- [x] **Aula 07:** Implementação do CRUD completo (PessoaService, DTOs e rotas).
- [ ] **Aula 08:** Migração do SQLite para a base de dados MySQL.
- [ ] **Aula 09 e 10:** Implementação de Autenticação e Segurança com JWT.
- [ ] **Aula 11:** Integração com APIs externas.
- [ ] **Aula 12:** Implementação de Testes Unitários.

## 🛠️ Como correr o projeto
1. Instalar dependências: `npm install`
2. Iniciar o servidor: `npm run start`
